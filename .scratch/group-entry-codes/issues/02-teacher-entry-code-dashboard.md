# 02: Teacher web entry-code dashboard

**What to build:** In the teacher group page, the owner can turn entry codes on or off, generate a code with a use limit, and see a simple dashboard of every code: the code, maximum uses, used count, whether it is used up, and which students used it. Each code can show its QR code and join link.

**Blocked by:** 01.

**Status:** done

- [x] Group settings include a “requires entry code” toggle.
- [x] The group page has an entry-codes tab.
- [x] The teacher can generate a code with a use limit of at least 1.
- [x] The dashboard lists code, max uses, used count, status, and usage names/timestamps.
- [x] Each code shows a scannable QR code and copyable join link.
- [x] Another teacher cannot read or generate codes for the group.
