# 56: Attendance marking

**What to build:** Give teachers a way to mark attendance. The `lesson_attendance` data already exists but has no UI or write endpoint.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] A teacher can mark each student present or absent for a lesson/group session.
- [ ] The mark is persisted and reflected in the existing attendance statistics.
- [ ] Only the owning teacher can read or write attendance for their group.
- [ ] The UI explains the empty state and works on mobile widths.
- [ ] Access rules in `docs/security.md` still hold.
- [ ] Checked in Arabic and English at 360 / 768 / 1280.
