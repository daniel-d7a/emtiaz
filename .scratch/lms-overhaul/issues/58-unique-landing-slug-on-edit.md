# 58: Unique public landing slug on edit

**What to build:** Validate that a teacher's public landing slug is unique when editing. A duplicate must be rejected before the form appears saved.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Editing a landing slug to one used by another teacher returns a clear conflict error.
- [ ] The form does not show a saved state when the slug is rejected.
- [ ] The teacher's own current slug can be saved unchanged.
- [ ] The error is shown in Arabic and English.
- [ ] Checked at 360 / 768 / 1280.
