# 09: Student course browser

**What to build:** A student-facing course catalogue and the same browser on public pages: search by name and filter by teacher, specialization, grade, course type, and semester. Cards use each teacher's theme.

**Blocked by:** 01, 02, 04, 06.

**Status:** ready-for-agent

- [ ] Students can search and combine filters; filters apply on the server where possible.
- [ ] Public pages offer the same browser without exposing unpublished courses.
- [ ] Cards are teacher-themed, show the relevant course data, and link to the detail view.
- [ ] Empty and loading states are explicit in both languages.
