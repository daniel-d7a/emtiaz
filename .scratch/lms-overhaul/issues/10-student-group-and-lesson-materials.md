# 10: Student group page and lesson materials

**What to build:** A themed group page with a course banner, teacher name/link, and units in order with the current unit highlighted. Lessons and quizzes appear as ordered items with locked/done/current badges. A lesson page has a materials sidebar (name, type icon); previewable materials render inline, others open in a new tab.

**Blocked by:** 01, 02, 04, 06.

**Status:** ready-for-agent

- [ ] Units are ordered, quizzes sit among lessons, and the current unit is highlighted.
- [ ] Locked, done, and current states are visible and match the pacing rules.
- [ ] Materials sidebar renders every attachment with the correct type icon.
- [ ] Images, PDFs, and embeds preview inline; unsupported types open in a new tab.
- [ ] Group cards use badges for status/counts; banner and cards use the teacher theme.
- [ ] Layout works at mobile width without horizontal scrolling.
