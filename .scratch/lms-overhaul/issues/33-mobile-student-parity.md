# 33: Mobile student parity

**What to build:** Students can do on mobile what the web student surface offers: home stats and latest courses, the course browser, themed group/unit views, lesson materials, quizzes, and profile editing.

**Blocked by:** 31, 06, 08, 09, 10, 11.

**Status:** ready-for-agent

- [ ] Home shows stats, latest courses, and notifications.
- [ ] The course browser supports search and the same filters as web.
- [ ] Group pages show units, locked/done states, and materials with inline preview where possible.
- [ ] Quizzes can be solved and revisited with results.
- [ ] Profile edits persist; nothing requires the web app.
