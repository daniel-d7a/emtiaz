# 16: Quiz builder

**What to build:** A modal launched from the unit header builds a quiz: name, questions with image and/or text, a radio button marking the correct answer, and 2–4 MCQ options. Quizzes appear as small items beside lessons and reorder among them. The unit-quiz visibility bug is fixed.

**Blocked by:** 14.

**Status:** ready-for-agent

- [ ] Quiz creation is a modal with better placeholders and full-width, single-column answer inputs.
- [ ] MCQ supports 2–4 options; true/false is supported; the correct answer is chosen by radio.
- [ ] A question can be text-only, image-only, or text plus image.
- [ ] Created quizzes appear in the unit, reorder with lessons, and remain visible after reload.
- [ ] Short-answer questions are not offered.
